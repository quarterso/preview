Get started

Quickstart

Take a Stripe test payment to an unlocked plan, credits added, and one credit spent.

This walks one Stripe test payment through Quarter with a test key. It takes a handful of requests and a Stripe account in test mode.

Before you start

You need a test API key, which starts with qk_test_, and your API URL. During early access, Quarter gives you both. A test key only ever sees test data.

1. Create an app

An app is one product you sell, with its stores, its products and its users. Keep its id. The response also carries setup_urls: the addresses Stripe and the App Store should call, known before you connect either.

2. Connect Stripe

  1. In the Stripe dashboard, in test mode, add a webhook endpoint with the URL from setup_urls.stripe and the events listed in Connecting Stripe. Stripe then shows its signing secret, which starts with whsec_.
  2. Create a restricted key with Read access to Checkout Sessions and Subscriptions, and nothing else. It starts with rk_test_.
  3. Give both to Quarter.

3. Say what your plan grants

A product ties a store product to what it grants. Here a Stripe price unlocks the pro entitlement and adds 200 credits each period, which expire at the end of it.

4. Take a test payment

Create the Checkout Session with your own user id in client_reference_id, and pay it with one of Stripe's test cards.

5. Report the purchase

On your success page, send the session id to Quarter. Quarter fetches the session from Stripe, unlocks pro, adds the credits, and answers with the user's access. When the Stripe webhook arrives later, it changes nothing.

6. Ask what the user has

7. Spend a credit

Use an id from your own system as the idempotency key, such as the id of the AI generation. Sending the same request again spends nothing more and answers "replayed": true.

Next

  • Register a webhook endpoint to hear about renewals, cancels and refunds as they happen.
  • Turn on the mirror to check access with a query against your own database.
  • Connect the App Store or Google Play.
