API reference

Customers and access

Ask what a user has right now, ask the stores again, grant free access, link ids, and export or erase a user.

Send your API key as authorization: Bearer <key> and JSON bodies as content-type: application/json. Errors use the shape in Errors.

Access

Retrieve access

GET/v1/apps/{app}/customers/{user}/accessAuth: API key

What this user has right now: entitlements by name, credit balances by currency, and every purchase behind them. An entitlement is active while any purchase that grants it gives access.

A user Quarter has never seen gets empty access, not an error.

Path parameters

FieldTypeRequiredDescription
appstringYesThe app id, starting with app_.
userstringYesYour own id for the user, 1 to 256 characters. Quarter never needs a name or email.

Retrieve access for many users

POST/v1/apps/{app}/access/batchAuth: API key

Access for up to 100 users at once, in the order given.

Path parameters

FieldTypeRequiredDescription
appstringYesThe app id, starting with app_.

Body

FieldTypeRequiredDescription
usersstring[]Yes1 to 100 of your user ids.

Ask the stores again

POST/v1/apps/{app}/customers/{user}/syncAuth: API key

For the user who says they paid and are locked out. Quarter asks each store again about everything this user bought, through the same checks a webhook goes through, and answers with the new access.

Each purchase gets a result: unchanged, updated, not_found, unreachable or skipped. A store that does not answer never takes access away. A user can be synced once every 10 seconds.

Path parameters

FieldTypeRequiredDescription
appstringYesThe app id, starting with app_.
userstringYesYour own id for the user, 1 to 256 characters. Quarter never needs a name or email.

Free access

Grant an entitlement

POST/v1/apps/{app}/customers/{user}/entitlementsAuth: API key

Gives the user an entitlement without a purchase, for a trial, a partner or support. Answers with the new access.

Path parameters

FieldTypeRequiredDescription
appstringYesThe app id, starting with app_.
userstringYesYour own id for the user, 1 to 256 characters. Quarter never needs a name or email.

Body

FieldTypeRequiredDescription
entitlementstringYesA lowercase name, such as pro.
duration_daysintegerNoHow long it lasts, from 1 to 3650 days.
expires_atstringNoAn ISO date in the future. Give this or duration_days, not both. With neither, it lasts until you end it.
idempotency_keystringYesYour own id for this operation, up to 200 characters. A retry with the same key does nothing more.

End a granted entitlement

DELETE/v1/apps/{app}/customers/{user}/entitlements/{entitlement}Auth: API key

Ends the free access you granted. Purchases that grant the same entitlement are not touched. Answers with the new access.

Path parameters

FieldTypeRequiredDescription
appstringYesThe app id, starting with app_.
userstringYesYour own id for the user, 1 to 256 characters. Quarter never needs a name or email.
entitlementstringYesThe entitlement name.

Ids

Link another id

POST/v1/apps/{app}/customers/{user}/aliasesAuth: API key

When a user who bought anonymously signs in, link the anonymous id to their account id. Purchases and credits under the alias move to the user, and both ids then answer with the same access.

Path parameters

FieldTypeRequiredDescription
appstringYesThe app id, starting with app_.
userstringYesYour own id for the user, 1 to 256 characters. Quarter never needs a name or email.

Body

FieldTypeRequiredDescription
aliasstringYesThe other id, such as the anonymous id used before sign-in.

Data requests

Export a user

GET/v1/apps/{app}/customers/{user}/exportAuth: API key

Everything Quarter holds about one user. See User data requests.

Path parameters

FieldTypeRequiredDescription
appstringYesThe app id, starting with app_.
userstringYesYour own id for the user, 1 to 256 characters. Quarter never needs a name or email.

Erase a user

DELETE/v1/apps/{app}/customers/{user}Auth: API key

Deletes the user, their aliases and their credit history, removes their id from stored store records, and deletes their mirror row. Purchases stay as anonymous records. This cannot be undone.

Path parameters

FieldTypeRequiredDescription
appstringYesThe app id, starting with app_.
userstringYesYour own id for the user, 1 to 256 characters. Quarter never needs a name or email.
