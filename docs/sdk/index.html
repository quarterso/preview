Get started

TypeScript SDK

Access checks, credit holds for AI calls, purchase reports and webhook verification from your backend, with last known access during an outage.

The SDK is coming to npm. During early access, Quarter shares it with you directly.

Use the SDK from your backend only. Your API key must never reach a browser or a phone.

Check access

quarter.accessMany(users) answers for up to 100 users in one request.

When Quarter cannot be reached

If Quarter does not answer, access and hasAccess return the last answer they had for that user, for up to an hour, marked stale: true. An outage never locks out a paying user. Writes such as spends and holds never fall back: they fail with an error. Set whenUnreachable: "deny" to fail instead, or lastKnownForSeconds to change the hour.

Charge for AI calls

withReservation holds up to max credits, runs your function, and spends the used it returns. If your function throws, everything held goes back. See Credits.

quarter.credits.spend, grant, reserve, settle and release are there too, for when you need them one by one. A short balance throws a QuarterError with the code insufficient_credits.
