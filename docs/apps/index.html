API reference

Apps and sources

Create apps, connect Stripe, the App Store and Google Play, set up the mirror, and read revenue metrics.

Send your API key as authorization: Bearer <key> and JSON bodies as content-type: application/json. Errors use the shape in Errors.

Apps

Create an app

POST/v1/appsAuth: API key

Returns the app with status 201.

Body

FieldTypeRequiredDescription
namestringYesA name for your own reference.
record_retention_daysintegerNoHow long store records are kept, from 30 to 3653 days. Defaults to 2557, about seven years.

List apps

GET/v1/appsAuth: API key

Every app in the project of your API key, oldest first.

Retrieve an app

GET/v1/apps/{app}Auth: API key

The app and its connected sources, with the URL each store should call.

Path parameters

FieldTypeRequiredDescription
appstringYesThe app id, starting with app_.

Sources

Connect Stripe

PUT/v1/apps/{app}/sources/stripeAuth: API key

Sets or replaces the Stripe source. Both secrets are stored encrypted. See Connecting Stripe for the key permissions and the webhook events.

Path parameters

FieldTypeRequiredDescription
appstringYesThe app id, starting with app_.

Body

FieldTypeRequiredDescription
restricted_keystringYesA Stripe restricted key with read access, rk_test_ in a test project and rk_live_ in a live one.
webhook_secretstringYesThe signing secret of the Stripe webhook endpoint, starting with whsec_.

Connect the App Store

PUT/v1/apps/{app}/sources/app_storeAuth: API key

Sets or replaces the App Store source. See Connecting the App Store.

Path parameters

FieldTypeRequiredDescription
appstringYesThe app id, starting with app_.

Body

FieldTypeRequiredDescription
bundle_idstringYesYour app's bundle id.
app_apple_idintegerNoYour app's Apple id. Apple requires it to verify production data.
key_idstringNoApp Store Server API key id.
issuer_idstringNoApp Store Server API issuer id.
private_keystringNoApp Store Server API private key, as PEM. Stored encrypted.

Connect Google Play

PUT/v1/apps/{app}/sources/play_storeAuth: API key

Sets or replaces the Google Play source. The push_url carries a new secret token and is shown only in this response. See Connecting Google Play.

Path parameters

FieldTypeRequiredDescription
appstringYesThe app id, starting with app_.

Body

FieldTypeRequiredDescription
package_namestringYesYour app's package name.
service_account_jsonstringYesThe service account's JSON key file, as a string. Stored encrypted.

Mirror

Set up the mirror

PUT/v1/apps/{app}/mirrorAuth: API key

Tests the connection, creates the table if it does not exist, and starts writing each user's access to it. See Mirror to your database.

Path parameters

FieldTypeRequiredDescription
appstringYesThe app id, starting with app_.

Body

FieldTypeRequiredDescription
connection_stringstringYesA postgres:// URL on a public address. Stored encrypted.
tablestringNoA lowercase SQL name. Defaults to quarter_access.

Retrieve the mirror

GET/v1/apps/{app}/mirrorAuth: API key

Where the mirror writes, when it last wrote, and the last error. The connection string is never returned.

Path parameters

FieldTypeRequiredDescription
appstringYesThe app id, starting with app_.

Metrics

Retrieve metrics

GET/v1/apps/{app}/metricsAuth: API key

Revenue as the stores report it, in each currency separately. MRR spreads each paying subscription's price over its billing period. Trials count as active but not as revenue.

Path parameters

FieldTypeRequiredDescription
appstringYesThe app id, starting with app_.
