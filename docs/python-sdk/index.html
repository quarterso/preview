Get started

Python SDK

Install the Python client, execute an action with the lost-response pattern, and use async, shadow mode, webhook and proof verification, listing and export.

The Python client covers the same API as the TypeScript SDK. It needs Python 3.10 or later and depends only on httpx, plus cryptography for proof verification. The package is quarter, published as the distribution quarterso. It has a sync client, Quarter, and an async one, AsyncQuarter.

Install

The package is not published to PyPI yet. For now, install it from the private repository over SSH. The proofs extra adds cryptography for offline proof verification.

The base URL comes from base_url=, then from QUARTER_API_URL, then defaults to http://localhost:8080. The API key is the first argument.

Execute an action

Give the ActionIntent an id derived from the business operation, never from the attempt. execute returns an ActionView; branch on state. It never retries on its own. A 202 is a return value, not an error. See Handling states.

Lost responses

If the response to execute is lost, the write may or may not have reached Quarter. The SDK raises QuarterTransportError and sets maybe_executed to True when it cannot rule that out. Resend the same intent: Quarter returns the existing action instead of running it again. Never mint a new id here. See Idempotency.

GET requests retry up to twice on network errors and 503. Writes retry only when you pass idempotency_key=. To wait for a proven outcome, use execute_and_wait. It polls until the action settles and raises QuarterPendingError when timeout (default 60 seconds) runs out.

Async

AsyncQuarter has the same surface. Every call is awaited, and lists and events.stream() use async for.

Shadow mode

quarter.shadow runs your own provider call unchanged, returns its result or re-raises its error, and records the observation in the background. Call flush() before a short-lived process exits. See Shadow mode.

Verify a webhook

construct_event verifies the quarter-signature header against the raw body, then parses it. Pass the exact bytes you received, before any JSON parsing. It raises QuarterSignatureError on a bad signature or a timestamp more than 300 seconds from your clock. Dedupe by event.id. See Webhooks.

quarter.events.stream() yields events live and resumes with Last-Event-ID after a dropped connection.

Verify a proof

verify_proof checks the Ed25519 signature offline against the keys from proof_keys() and returns False for a bad signature, a changed body, or an unknown keyId. Cache the keys. See Signed proofs.

List and export

Lists are iterators over every page. Call .page() to get one page instead. Filters are keyword arguments: state, provider, action_type, subject, since, until (a string or a datetime) and metadata (a dict of strings). limit sets the page size. export takes the same filters and returns the ledger as CSV, without paging.
