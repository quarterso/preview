Operate

Errors

Every error code the API and SDK return, with its HTTP status and what to do.

An error means Quarter refused or could not process the request. It is never used for an uncertain outcome: OUTCOME_UNKNOWN, NEEDS_REVIEW and a throttled provider arrive as the action's state with HTTP 202.

Error body

Every error response has the same shape. code is stable; branch on it. message is for people and can change. details is present for some codes.

The SDK throws QuarterError with code, status, message, details and requestId. ACTION_ID_CONFLICT is thrown as ActionIdConflictError; isActionIdConflict(error) checks for it.

API error codes

CodeHTTPWhenWhat to do
UNAUTHORIZED401The API key is missing, malformed, unknown or revoked. Also an executor token or signature that does not verify, or a provider webhook signature that does not verify.Check the authorization: Bearer header and that the key is active. Do not retry with the same key.
FORBIDDEN403You are signed in, but your team role cannot do this. Viewers read; developers operate on actions; owners manage policy, keys, team and webhooks.Do not retry. Ask an owner to change your role or to make the change.
POLICY_DENIED403A deny_action or require_actor_type rule matched. The action exists and is NOT_EXECUTED; details.action has its view.Do not retry. Change the policy or the actor if the denial is wrong.
ACTION_NOT_FOUND404No action with that id in this project.Check the id and its URL encoding (: becomes %3A).
RESOURCE_NOT_FOUND404No such webhook endpoint, active API key, or open spec block.List the resource to find its current id.
ACTION_ID_CONFLICT409The action id exists with a different fingerprint (action, input or subject changed). Nothing was dispatched. details.fingerprint is the stored one.A bug in id construction, or a genuinely new operation. Fix the id scheme, or use a new id such as :v2 for a new operation.
EXECUTION_IN_PROGRESS409Another request or worker moved the action on while this one ran, or an executor reported on a lease it no longer holds.Read the action with GET /v1/actions/{actionId} and act on its current state.
VERSION_CONFLICT409PUT /v1/policy sent an expectedVersion that is no longer current. Nothing was written.Read the policy again, reapply your change, and send the new version.
VALIDATION_FAILED400The request body is not valid JSON. message is request body is not valid JSON.Send a well-formed JSON body with content-type: application/json.
VALIDATION_FAILED422The request body or query does not match the endpoint schema, or the action input does not match the ActionSpec's inputSchema. For action input, the action is recorded as NOT_EXECUTED and details.action has its view. Also returned when revoking the last active API key.Fix the request. For action input, a corrected request is a new write: use a new id.
ACTION_SPEC_NOT_FOUND422No ActionSpec exists for action.Check the name against the actions reference.
ACTION_SPEC_NOT_CERTIFIED422A production key sent an action whose spec is experimental or preview, or the action type is blocked by an open spec block (details.specBlockId).Use a sandbox key, or review and clear the spec block. See spec blocks.
INVALID_MANUAL_RESOLUTION422resolve was called on an action that is not NEEDS_REVIEW or OUTCOME_UNKNOWN, or CONFIRMED was sent without evidence.providerObjectId.Read the action's current state. Include the provider object id when confirming.
RATE_LIMITED429More than 1200 requests in one minute for one API key. x-ratelimit-limit, x-ratelimit-remaining and x-ratelimit-reset describe the window.Back off until the reset. Retrying execute with the same intent is safe.
INTERNAL500An unexpected server error.For execute, resend the same intent: the server may have accepted it. Report the quarter-request-id if it persists.

SDK error codes

These come from the SDK itself, not from a response body.

CodeHTTPWhenWhat to do
TRANSPORT_ERROR0QuarterTransportError: no response (timeout, reset, DNS), or a 5xx or unreadable body on a POST. maybeExecuted is true for POSTs.Resend the same intent. Never create a new action id.
INVALID_SIGNATURE400QuarterSignatureError from constructEvent: the webhook header is malformed, too old, or does not match.Answer the delivery with 400. Check you pass the raw body and the right endpoint secret.
INVALID_RESPONSE2xxA GET returned a success status with a body that is not JSON.Retry the read.

Retrying safely

  • execute with the same intent is always safe to repeat. Quarter returns the existing action.
  • 4xx errors other than 409 EXECUTION_IN_PROGRESS and 429 will fail the same way again. Fix the request first.
  • The SDK retries GET requests twice on network errors and 503. It never retries a POST, because a lost response cannot prove the request was not processed.
