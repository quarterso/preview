API reference

Products

Say what each store product grants: entitlements, credits, or both.

Send your API key as authorization: Bearer <key> and JSON bodies as content-type: application/json. Errors use the shape in Errors.

A product must grant entitlements, credits, or both. Each store product can be configured once per app.

Create a product

POST/v1/apps/{app}/productsAuth: API key

Returns the product id with status 201.

Path parameters

FieldTypeRequiredDescription
appstringYesThe app id, starting with app_.

Body

FieldTypeRequiredDescription
sourcestringYesstripe, app_store or play_store.
store_product_idstringYesThe Stripe price id, the App Store product id, or the Play product id.
kindstringNosubscription (the default), non_consumable or consumable.
entitlementsstring[]NoLowercase names this product unlocks, such as pro. A consumable grants none.
creditsobjectNo{ currency, amount, expires }: credits added for each period or purchase. expires is never (the default) or period_end, for subscriptions only.
pricenumberNoThe price, used only for metrics.
currencystringNoThe price currency, such as USD.
period_daysintegerNoThe billing period in days, used only for metrics.

List products

GET/v1/apps/{app}/productsAuth: API key

Every product of the app, oldest first.
