API reference

Credits API

Hold credits for an AI call and settle what it used, spend credits atomically, and grant credits.

Send your API key as authorization: Bearer <key> and JSON bodies as content-type: application/json. Errors use the shape in Errors.

Balances appear in access. How credits work is in Credits.

Hold credits

POST/v1/apps/{app}/customers/{user}/credits/reservationsAuth: API key

Holds credits while a call runs. Held credits leave the balance at once. Fails with insufficient_credits when the balance is too low. Returns the reservation with status 201.

Path parameters

FieldTypeRequiredDescription
appstringYesThe app id, starting with app_.
userstringYesYour own id for the user, 1 to 256 characters. Quarter never needs a name or email.

Body

FieldTypeRequiredDescription
currencystringYesA lowercase name you choose, such as credits or tokens.
amountnumberYesA positive amount, with up to six decimals.
idempotency_keystringYesYour own id for this operation, up to 200 characters. A retry with the same key does nothing more.
expires_in_secondsintegerNoWhen an unsettled hold is released, from 30 to 86400 seconds. Defaults to 900.

Settle a hold

POST/v1/apps/{app}/customers/{user}/credits/reservations/{reservation}/settleAuth: API key

Spends what the call used, up to the amount held, and returns the rest. Settling again with the same amount answers the same. Settling a closed hold differently fails with reservation_closed.

Path parameters

FieldTypeRequiredDescription
appstringYesThe app id, starting with app_.
userstringYesYour own id for the user, 1 to 256 characters. Quarter never needs a name or email.
reservationstringYesThe reservation id, starting with res_.

Body

FieldTypeRequiredDescription
amountnumberYesWhat the call used. 0 releases the whole hold.

Release a hold

POST/v1/apps/{app}/customers/{user}/credits/reservations/{reservation}/releaseAuth: API key

Returns the whole hold to the balance, for a call that failed.

Path parameters

FieldTypeRequiredDescription
appstringYesThe app id, starting with app_.
userstringYesYour own id for the user, 1 to 256 characters. Quarter never needs a name or email.
reservationstringYesThe reservation id.

Spend credits

POST/v1/apps/{app}/customers/{user}/credits/spendAuth: API key

Atomic: the balance never goes below zero, and a retry with the same idempotency key is the same spend, answered with "replayed": true. Fails with 409 insufficient_credits when the balance is too low, including when the user has no credits at all.

Path parameters

FieldTypeRequiredDescription
appstringYesThe app id, starting with app_.
userstringYesYour own id for the user, 1 to 256 characters. Quarter never needs a name or email.

Body

FieldTypeRequiredDescription
currencystringYesA lowercase name you choose, such as credits or tokens.
amountnumberYesA positive amount, with up to six decimals.
idempotency_keystringYesYour own id for this operation, up to 200 characters. A retry with the same key does nothing more.
metadataobjectNoYour own data, kept with the entry.

Grant credits

POST/v1/apps/{app}/customers/{user}/credits/grantAuth: API key

Adds credits without a purchase, for a bonus or a support gesture. A retry with the same idempotency key adds nothing more.

Path parameters

FieldTypeRequiredDescription
appstringYesThe app id, starting with app_.
userstringYesYour own id for the user, 1 to 256 characters. Quarter never needs a name or email.

Body

FieldTypeRequiredDescription
currencystringYesA lowercase name you choose, such as credits or tokens.
amountnumberYesA positive amount, with up to six decimals.
idempotency_keystringYesYour own id for this operation, up to 200 characters. A retry with the same key does nothing more.
expires_atstringNoAn ISO date when these credits expire. Without it, they never do.
