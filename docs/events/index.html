API reference

Events and webhook endpoints

Read the event log, register webhook endpoints, and replay deliveries.

Send your API key as authorization: Bearer <key> and JSON bodies as content-type: application/json. Errors use the shape in Errors.

Events

List events

GET/v1/eventsAuth: API key

The newest events in the project first. Events are append-only and never change.

Query parameters

FieldTypeRequiredDescription
object_idstringNoOnly events about this object, such as a customer id.
limitintegerNoHow many to return, up to 200. Defaults to 50.

Webhook endpoints

Create a webhook endpoint

POST/v1/webhook_endpointsAuth: API key

Returns the endpoint with status 201. The secret is shown only in this response. See Webhooks to verify signatures.

Body

FieldTypeRequiredDescription
urlstringYesA public https URL.
enabled_eventsstring[]NoThe event types to send. Without it, the endpoint receives every type.

List webhook endpoints

GET/v1/webhook_endpointsAuth: API key

Every endpoint in the project. Secrets are never returned.

Deliveries

List deliveries

GET/v1/webhook_deliveriesAuth: API key

The latest 100 deliveries, with their status and the last response.

Query parameters

FieldTypeRequiredDescription
eventstringNoOnly the deliveries of this event id.

Retry a delivery

POST/v1/webhook_deliveries/{id}/retryAuth: API key

Sends a delivery again now, whatever its state.

Path parameters

FieldTypeRequiredDescription
idstringYesThe delivery id, starting with whd_.
