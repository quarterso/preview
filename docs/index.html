Connect an agent

Point the agent’s base URL at Quarter and add three headers. Its vendor key stays the same.

HeaderUse
x-quarter-keyRequired. An agent key from QUARTER_AGENT_KEYS.
x-quarter-agentRequired. Which agent is spending.
x-quarter-taskOptional. The task or run, for caps and reports.
x-quarter-customerOptional. The end customer the call serves.
x-quarter-approvalOptional. An approved approval id, to retry a held call once.
