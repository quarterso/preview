For design partners. The gateway runs on your own server. Access is shared during pre-release.

Run the gateway

init writes .env with fresh keys and caps.json with $100 a month in total.

Run the other commands from the same folder, with --env-file .env too. In a container, the image takes all config from the environment.

Connect an agent

Point the agent at the gateway and give it the agent key from .env as its API key. The gateway swaps in the real vendor key.

Claude Code

This starts Claude Code pointed at the gateway with the agent key, as agent claude-code. Signed in with Claude Pro or Max, calls stay on the subscription: Quarter applies loop stops and approvals, records them at no cost, and answers x-quarter-billing: subscription. If .env holds ANTHROPIC_API_KEY, Claude Code uses that key instead. To make Quarter the only place company machines may send Claude Code, put its address in managed settings with allowedProviders: ["customEndpoint"].

Caps and prices

FieldValues
scopeagent, task, customer, or all
keyAn id, or * (the default) for each one
windowday, month or total
limit_usdThe cap
approve_above_usdOptional. Single calls above this wait for approval

List prices for OpenAI, Anthropic, Gemini and OpenRouter are built in, cache prices included. prices.json adds vendors and overrides models. A model with no price is never treated as free: it is charged at the highest prices known for that vendor.

Egress rules

Agents hold only their Quarter key. The gateway holds the real keys and the rules.

The first rule that matches wins. deny answers 403 rule_denied; approve waits for a person. Tool rules apply to non-streamed replies from Anthropic Messages, OpenAI Chat Completions and OpenAI Responses. Streamed replies pass through unchanged and are not checked.

Why a task cost that

The task is x-quarter-task, or Claude Code's session id. It shows the total charged and at list price, what cache misses cost, the shares of tool definitions, system prompt, history and output, cost per subagent and per prompt, and each cache break with its cause. The same report is GET /tasks/<task>/why.

Loop stops

On by default. A paused agent or task gets 423 until a person resumes it.

Approvals and reports

The dashboard is at /dashboard. The password is the admin key or your own key from QUARTER_PEOPLE. For approvals in Slack, set QUARTER_SLACK_BOT_TOKEN, QUARTER_SLACK_SIGNING_SECRET, QUARTER_SLACK_CHANNEL and QUARTER_SLACK_USERS.

Payments

x402 and MPP payments get the same caps, approvals and pauses through two calls.

CallUse
POST /authorizeBefore paying. Quarter holds the amount and answers with a call_id and a signed authorisation, valid 10 minutes.
POST /settleAfter paying. The hold becomes the real charge. Settling 0 releases it.
