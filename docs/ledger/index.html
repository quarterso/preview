Outcomes

Ledger search and export

Find actions by state, provider, subject, time or your own metadata, and export the ledger as CSV.

Every action is a row in an append-only ledger, with its full event timeline behind it. Search it from code to answer support questions (what happened to order 1042), and export it for audits and spreadsheets.

Tag actions with metadata

metadata on an intent is a flat object of string values. It is stored with the action and is not sent to the provider. Use it for the ids your own systems search by.

Search

GET /v1/actions returns the newest actions first, with cursor pagination. Every filter is optional and filters combine with AND.

Query parameterMatches
stateOne state, or several separated by commas: OUTCOME_UNKNOWN,NEEDS_REVIEW.
providerEvery action type of one provider, for example stripe.
actionTypeOne action type, for example stripe.refund.create.
subjectThe exact subject.
since, untilCreation time, ISO 8601. since is inclusive, until exclusive.
metadata.<key>Exact value of one metadata key. Repeat for several keys. Keys are letters, digits and underscores.
limitPage size, 1 to 200. Default 50.
cursornextCursor from the previous page.

From the terminal, quarter actions --state NEEDS_REVIEW --provider stripe lists the 20 most recent matches.

Export as CSV

GET /v1/actions/export returns the project's actions as CSV, oldest first, up to 100,000 rows. It takes the same filters as the list (state, provider, actionType, subject, since, until and metadata.*), without paging; for a larger ledger, export in time windows. The response is text/csv with content-disposition: attachment; filename="quarter-actions.csv". Fields that contain a comma, quote or newline are quoted.

ColumnContent
action_idYour action id.
action_typeFor example stripe.refund.create.
current_stateThe action's state at export time.
reasonShort explanation for the state, when there is one.
subject_idThe subject you sent.
actor_type, actor_idWho asked for the write.
payload_fingerprintHash of action, input and subject.
spec_versionThe ActionSpec version the plan was compiled from.
created_at, updated_atISO 8601, UTC.
The export has one row per action, not per event, and no metadata column. For evidence, read GET /v1/actions/{actionId}/events or the signed proof.
