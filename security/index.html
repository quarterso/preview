Pre-release

Built to hold as little as possible

Quarter needs to know what a call costs and who made it. It keeps nothing else.

How it is built

  • Vendor keys pass through

    Your agent’s vendor key travels with the call and is never written down.

  • No prompts kept

    Quarter reads usage from the reply. Prompts and answers are never stored.

  • No money moves

    Quarter decides and records. Vendors are paid the way you pay them today.

  • Runs on your server

    One container on infrastructure you control. The ledger stays with you.

  • Keys from the environment

    Agent and admin keys are set on the server, never in files, and compared in constant time.

  • Closed by default

    The gateway will not listen beyond the machine without agent keys set.
