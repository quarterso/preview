Watch Quarter prove a lost refund in five minutes.

Lose a refund's response on purpose and watch Quarter confirm it. The sandbox is simulated, so no Stripe account. Packages ship with early access.

Quickstart From code

A lost response, resolved with proof.

  1. Get a sandbox key and the CLI

    No Stripe account needed.

  2. Lose a refund's response on purpose

    Stripe applies the refund and never answers.

  3. Watch Quarter check Stripe

    OUTCOME_UNKNOWN, then CONFIRMED. The simulator shows one refund.

  4. Verify the proof offline

    The CLI checks the signature on your machine.

Illustrative example

The same refund, from your backend.

  1. Install the SDK

    Node 22 or later, or Python.

  2. Send the write with a stable ID

    Derive it from the business operation, never the attempt.

  3. Branch on the state

    Five states, none of them an exception.

  4. Or start in shadow mode

    Your code still makes the call. Quarter records what happened.

refund.ts
1const result = await quarter.actions.execute({2  id: `refund:${order.id}:v1`,3  action: "stripe.refund.create",4  actor: { type: "service", id: "billing-api" },5  input: { paymentIntent: order.paymentIntent, amount: 12900 },6});7// result.state: CONFIRMED, NOT_EXECUTED,8// SAFE_TO_RETRY, NEEDS_REVIEW or OUTCOME_UNKNOWN
