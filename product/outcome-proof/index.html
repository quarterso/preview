Built to be checked.

  • Categories, not confidence scores

    Each proof names how Quarter knows. Heuristic evidence never closes an action on its own.

  • Uncertainty stays in the history

    Events are only appended. An action that was unknown, then confirmed, keeps both facts.

  • No keys, no raw bodies

    Provider keys are never stored. Raw request and response bodies are kept only if a project opts in.

  • A console for what needs a person

    Read timelines and proofs, and resolve what automation could not. No sign-in yet, so it runs behind your own access control.
