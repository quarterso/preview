Build status · 2026-09-29

What exists today, and what does not.

Quarter is pre-launch. Everything under Built runs in development with automated tests. Nothing carries production traffic yet.

Built

7 components

Engine

built
  • The state machine, the only code that changes an action's state
  • 58 ActionSpecs across 38 providers
  • Deterministic plan compiler with SHA-256 plan hashes
  • Provider simulators with fault injection and independent ground truth

Control plane API

built
  • 11 public endpoints, plus the agent protocol
  • Append-only PostgreSQL ledger with a projected current state
  • Execution leases with fencing tokens
  • Execution and reconciliation workers

Customer-side executor

built
  • One-time enrollment, then outbound polling only
  • Ed25519 plan verification and signed, redacted results
  • Local credentials for all 38 providers

TypeScript SDK

built
  • Zero runtime dependencies, Node 22
  • execute, plan, get, events, list, reconcile, resolve
  • Shadow mode

Python SDK

built
  • Sync and async clients, Python 3.10 or later
  • Not published yet: install from the private repository
  • Webhook and proof verification

ActionLint

built
  • Six rules for TypeScript and JavaScript
  • Text and JSON output, CI exit codes

Operator console

built
  • Action list with filters, timeline, Outcome Proof export
  • Manual review with audited resolutions
